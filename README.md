# Tucker Audio releases

Download builds of Tucker Audio's live sound tools. This repo holds release files only; there's no source code here.

More information and download links: https://tuckeraudio.co/software/

| App | What it does |
|---|---|
| Timescape | SMPTE timecode in, Yamaha DM7 scene recalls out (macOS 14+) |

All apps are in beta. Beta builds aren't notarised by Apple yet: the first time you open one, right-click it and choose Open.

Questions or bug reports: kieren@tuckeraudio.co
